**Low-level Android tinkerer**

## Projects

All projects target the **Xiaomi Redmi 4X (santoni)**, Snapdragon 435, 2 GB RAM, kernel 4.9.

| Project | Platform | Status |
|:--------|:---------|:-------|
| [**Matrixx 15**](https://github.com/ziachi/device_xiaomi_santoni) | Android 15 (V) | ✅ v14 built |
| [**DerpFest 13**](https://github.com/ziachi/device_xiaomi_santoni_derpfest) | Android 13 (T) | ✅ v12 released |
| [**Qassa**](https://github.com/ziachi/device_xiaomi_santoni_qassa) | Android 10 (Q) | ✅ v20 released |
| [**Qassa Ubuntu**](https://github.com/ziachi/santoni_qassa_ubuntu) | Ubuntu 22.04, headless | ✅ v1.1.1 released |

> **Qassa Ubuntu** converts the phone into a 24/7 arm64 Linux server: Android 10 reduced to kernel, Wi-Fi and a chroot, with sshd reachable over the LAN.
